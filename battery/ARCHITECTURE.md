# Go MQTT Broker 架构文档

## 概述

Go MQTT Broker 是一个高性能的 MQTT 代理实现，设计支持 100K+ 并发连接。该系统采用 Go 语言编写，利用其轻量级 Goroutine 和高效的并发模型来处理大规模客户端连接。

## 核心组件

### 1. Server (cmd/server/main.go)
- **职责**: 应用程序入口点，负责解析命令行标志、初始化 Broker 并处理优雅关闭
- **关键功能**:
  - 解析 `--address` 和 `--max-connections` 参数
  - 初始化 Broker 实例
  - 设置系统信号处理以实现优雅关闭

### 2. Broker (internal/broker/broker.go)
- **职责**: MQTT 协议的核心处理逻辑
- **属性**:
  - `listener`: TCP 监听器
  - `clients`: 客户端连接存储 (sync.Map)
  - `messages`: 消息通道 (10000 缓冲)
  - `connManager`: 连接管理器引用
  - `topicRouter`: 主题路由器引用
- **关键方法**:
  - `Start()`: 启动主循环，监听并接受新连接
  - `handleConnection()`: 处理单个客户端连接
  - `handlePacket()`: 处理不同类型的 MQTT 数据包
  - `handleSubscribe()/handleUnsubscribe()`: 订阅管理
  - `handlePublish()`: 发布消息处理
  - `processMessages()`: 消息路由协程
  - `routeMessage()`: 主题匹配和消息转发
  - `Stop()`: 优雅关闭

### 3. Connection Manager (internal/connection/)
- **职责**: 连接数限制、活跃连接监控、连接指标统计
- **关键功能**:
  - 强制执行最大连接数限制
  - 监控连接数和消息计数
  - 连接注册和注销

### 4. Topic Router (internal/router/)
- **职责**: 主题匹配、订阅管理、客户端-主题映射
- **关键功能**:
  - 存储订阅关系
  - 实现主题匹配算法 (支持通配符)
  - 根据主题查找订阅客户

### 5. 消息处理管道
- **发布-订阅模式**: 使用通道解耦发布者和订阅者
- **异步处理**: 发布的消息先进入缓冲通道，由单独的 Goroutine 处理
- **路由优化**: 消息路由独立于接收逻辑，防止慢速订阅者影响整体性能

## 高并发设计

### 1. 连接处理模式
- 每个客户端连接启动一个独立的 Goroutine
- 利用 Go 的 CSP 模型实现高效的并发控制
- 使用 `sync.Map` 管理客户端连接，支持高并发访问

### 2. 消息解耦
- 发布的消息通过通道异步传递
- 消息处理与网络 I/O 完全分离
- 防止慢消费者阻塞快生产者

### 3. 内存管理
- 使用 `sync.Pool` 重用缓冲区以减少 GC 压力
- 优化数据结构以减少内存分配
- 在热点路径上最小化内存分配

## 协议支持

### MQTT 3.1.1 协议实现
- **CONNECT / CONNACK**: 连接建立和确认
- **PUBLISH / PUBACK**: 消息发布 (QoS 0, 1)
- **SUBSCRIBE / SUBACK**: 主题订阅
- **UNSUBSCRIBE / UNSUBACK**: 取消订阅
- **PINGREQ / PINGRESP**: 心跳检测
- **DISCONNECT**: 连接断开

## 错误处理和恢复

### 优雅关闭
- 监听系统信号 (SIGINT, SIGTERM)
- 停止接受新连接
- 等待所有活动连接和处理协程完成
- 清理资源

### 容错机制
- 连接数限制防止资源耗尽
- 消息缓冲区溢出保护
- 网络错误和协议错误处理

## 性能优化

### 1. 减少锁竞争
- 使用 `sync.Map` 替代互斥锁保护的 map
- 最小化临界区范围
- 使用读写锁优化读多写少场景

### 2. 内存优化
- 复用数据结构
- 避免不必要的复制
- 使用适当的缓冲区大小

### 3. 网络 I/O 优化
- 批量读写操作
- 优化网络包大小
- 最小化系统调用次数

## 部署指南

### 最小系统要求
- 内存: 根据连接数而定，每个连接约需几 KB
- CPU: 多核处理器推荐
- 网络: 高带宽低延迟

```bash
./server --address ":1883" --max-connections 100000
```
