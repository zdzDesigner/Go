# 音频播放上下文

本上下文描述一个通过微信 H5 或 Android App 访问的音频库。音频由部署 server 管理，播放进度属于访问设备，不属于匿名访问者或服务端用户。Android App 使用 Tauri 内嵌 H5 页面，原生 Media3 服务负责后台播放，不读取手机本地音频。

## 语言

**音频库**：部署 server 上配置目录中的全部可播放音频资源集合。
_Avoid_: 音乐库、媒体中心

**音频资源**：音频库中的一个可被 H5 选择和播放的文件。
_Avoid_: 文件、媒体项

**微信设备**：承载微信 WebView 的具体设备，用于隔离本地续播记录。
_Avoid_: 用户、帐号、客户端

**App 设备**：安装 Android App 的设备。App 将续播记录按 server 地址和音频资源 ID 保存在设备本地，与微信设备的浏览器存储互不共享。

**续播记录**：微信设备或 App 设备针对某个音频资源保存的最近播放位置。微信 H5 使用 `localStorage`，Android 后台服务使用 `SharedPreferences`。
_Avoid_: 服务端进度、用户进度

**共享访问密钥**：启用访问控制时，所有访问者共用的单一访问凭证，不代表任何用户身份；访问控制也可以通过配置关闭。
_Avoid_: 密码、帐号密码、用户令牌
