# 项目知识库 - Go语言MQTT客户端开发指南

**生成时间:** 2026-02-19
**项目名称:** 自定义MQTT客户端
**分支:** main

## 项目概述
这是一个用Go语言实现的自定义MQTT客户端，支持TLS连接。客户端实现了核心MQTT操作，如连接、订阅、发布、取消订阅和ping。

## 构建命令

### 基础构建
```bash
# 构建项目
go build -o mqtt_client .

# 直接运行
go run .
```

## 代码风格指南

### 导入规范
- 按组导入：标准库 -> 第三方 -> 项目本地
- 使用显式导入路径
- 仅在包初始化副作用时使用空白导入

### 命名约定
- 函数/方法名使用驼峰式 (camelCase)
- 导出的函数/类型使用帕斯卡命名法 (PascalCase)
- 常量使用全大写下划线分隔 (SCREAMING_SNAKE_CASE)
- 使用描述性名称；避免缩写（除"i"、"err"等通用缩写）

### 错误处理
- 始终检查错误并适当处理
- 使用 %w 包装错误以保持上下文
- 对简单错误使用 errors.New()，对格式化错误使用 fmt.Errorf()
- 使用上下文信息记录错误

### 类型定义
- 为领域特定概念定义自定义类型
- 空结构体使用 struct{}
- 谨慎使用类型别名
- 导出公共API中的类型

### 结构体组织
- 将相关方法组合在一起
- 对修改结构体的方法使用指针接收器
- 对不修改结构体的方法使用值接收器
- 可能的情况下用有意义的零值初始化结构体字段

### 格式化标准
- 使用4个空格缩进（非Tab）
- 实际应用中限制行长度为100个字符
- 将相关常量分组
- 注释导出的函数/类型
- 内联注释使用 //，必要时块注释使用 /* */

### 并发模式
- 使用通道在goroutines之间通信
- 使用sync.WaitGroup协调goroutine完成
- 使用互斥锁保护共享数据访问
- 考虑使用context进行取消和超时

### MQTT协议特定事项
- MQTT消息类型定义为常量（CONNECT、CONNACK、PUBLISH等）
- 包ID应唯一并避免零值
- 适当地处理不同的QoS级别
- 为MQTT包实现正确的长度编码/解码
- 正确维护连接状态

### TLS安全
- 使用最低TLS版本1.2
- 生产环境中验证证书（避免在生产环境中使用InsecureSkipVerify）
- 设置适当的ServerName以便进行证书验证
- 实现适当的TLS握手验证

### 包结构
- 主包包含客户端实现和连接逻辑
- 相关类型和常量逻辑分组
- 协议特定逻辑封装在适当函数中
- 错误处理集中化

## 测试指南

- 使用表驱动测试测试单个函数（适当情况下）

- 需要时模拟外部依赖项
