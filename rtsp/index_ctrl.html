Instructions

  • Select the correct video resolution that matches your RTSP stream
  • Make sure the Go RTSP server is running on port 8080
  • Click "Connect" to start receiving video stream
  • Video will be decoded using WebCodecs API and rendered on canvas
  • Ensure your browser supports WebCodecs (Chrome 94+, Edge 94+)
