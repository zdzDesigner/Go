# 任务分解模板

## 任务优先级说明
- **P0**：必须完成，阻塞发布
- **P1**：重要，影响核心功能
- **P2**：增强，可延后处理

## 任务分组

### 第一阶段：基础设施
- [ ] **[P0]** 任务 1：初始化项目结构
  - **文件**：`go.mod`, `main.go`
  - **验收**：项目可编译通过
  - **依赖**：无

- [ ] **[P0]** 任务 2：实现 SSH 服务器框架
  - **文件**：`main.go:29-73`
  - **验收**：可接受 SSH 连接并完成握手
  - **依赖**：任务 1

### 第二阶段：核心功能
- [ ] **[P0]** 任务 3：实现路径映射与沙箱隔离
  - **文件**：`main.go:176-182` (`resolve()` 函数)
  - **验收**：通过路径穿越攻击测试
  - **依赖**：任务 2
  - **测试**：`resolve_test.go`

- [ ] **[P0]** 任务 4：实现文件读写接口
  - **文件**：`main.go:185-205` (`Fileread`, `Filewrite`)
  - **验收**：可上传/下载文件
  - **依赖**：任务 3

- [ ] **[P1]** 任务 5：实现目录操作
  - **文件**：`main.go:207-233` (`Filecmd`)
  - **验收**：支持 mkdir, rm, rename
  - **依赖**：任务 3

### 第三阶段：增强功能
- [ ] **[P1]** 任务 6：集成速率限制器
  - **文件**：`main.go:271-317` (`rateLimitedReaderAt`, `rateLimitedWriterAt`)
  - **验收**：传输速率在配置范围内波动 ±20%
  - **依赖**：任务 4
  - **测试**：性能测试脚本

- [ ] **[P1]** 任务 7：修复客户端退出挂起问题
  - **文件**：`main.go:108` (添加 `defer channel.Close()`)
  - **验收**：Ctrl+D 可正常退出
  - **依赖**：任务 2

### 第四阶段：测试与文档
- [ ] **[P0]** 任务 8：编写单元测试
  - **文件**：`*_test.go`
  - **验收**：覆盖率 > 70%
  - **依赖**：任务 3-6

- [ ] **[P1]** 任务 9：编写完整 README
  - **文件**：`README.md`
  - **验收**：包含安装、配置、使用、故障排查章节
  - **依赖**：所有功能完成

- [ ] **[P2]** 任务 10：性能基准测试
  - **文件**：`benchmark_test.go`
  - **验收**：记录各场景性能数据
  - **依赖**：任务 6
