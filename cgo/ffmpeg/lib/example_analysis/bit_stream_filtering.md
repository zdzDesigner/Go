✦ 这个Go程序是一个使用 go-astiav（一个FFmpeg的Go绑定库）的示例，其主要功能是演示如何对媒体文件进行比特流过滤 (Bit Stream Filtering)。

  具体来说，它的工作流程如下：

   1. 解析参数：程序接收两个命令行参数：
       * -i：指定输入的媒体文件路径。
       * -f：指定要使用的比特流过滤器名称（默认为 "null"，即什么也不做的过滤器）。

   2. 打开媒体文件：它打开指定的输入文件，并解析其中的媒体流信息（如视频流、音频流等）。

   3. 初始化过滤器：
       * 遍历文件中的所有流。
       * 如果流是音频或视频类型，程序就会为这个流创建一个由 -f 参数指定的比特流过滤器上下文。
       * 它将原始流的编解码器参数复制到过滤器中，并进行初始化。

   4. 逐包过滤：
       * 程序从输入文件中逐个读取编码后的数据包（Packet）。
       * 将读取到的数据包发送（SendPacket）到对应流的比特流过滤器中。
       * 然后，从过滤器接收（ReceivePacket）一个或多个处理后的新数据包。
       * 每当收到一个过滤后的新数据包，程序会打印一条日志，包含该数据包的流索引和PTS（Presentation Timestamp），以证明过滤操作已成功。

   5. 刷新与结束：
       * 当所有输入数据包都处理完毕后，程序会向过滤器发送一个nil包来“刷新”(flush) 过滤器，确保过滤器内部缓冲的所有数据都被处理和输出。
       * 最后打印 "success" 消息。

  总结：

  这个示例的核心目的是展示如何在不进行解码和重新编码的情况下，直接对编码后的数据（比特流）进行操作。这是一种非常高效的处理方式，常用于
  需要修改容器格式（例如，将 MP4 中的 H.264 转换为 Annex B
  格式以便在某些流媒体协议中使用）或对码流进行少量修改的场景。程序本身并不生成新的媒体文件，只是将过滤后的数据包信息打印到控制台。
